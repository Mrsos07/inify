🔐 المصادقة

جميع طلبات API تتطلب مفتاح API صالح. يمكنك الحصول على مفتاحك من لوحة التحكم.

إضافة المفتاح للطلبات

أضف المفتاح في Header الطلب:

HTTP Header 
Authorization: Bearer YOUR_API_KEY
Content-Type: application/json

مثال باستخدام cURL

cURL 
curl -X GET "https://api.newra.ai/v1/properties" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json"

⏱️ حدود الاستخدام

لضمان جودة الخدمة، هناك حدود للطلبات:

الباقة الطلبات/دقيقة الطلبات/يوم
المؤسسات 1,000 100,000
429 - تجاوز الحد المسموح

🏠 العقارات

GET /v1/properties

استرجاع قائمة جميع العقارات الخاصة بك

المعاملات (Query Parameters)

المعامل النوع الوصف
page integer رقم الصفحة (افتراضي: 1)
limit integer عدد النتائج (افتراضي: 20، أقصى: 100)
type string نوع العقار (apartment, villa, land, office)
listing_type string نوع العرض (sale, rent)
city string المدينة

مثال الاستجابة

JSON Response 
{
  "success": true,
  "data": {
    "properties": [
      {
        "id": "prop_abc123",
        "title": "شقة فاخرة في حي النرجس",
        "type": "apartment",
        "listing_type": "sale",
        "price": 850000,
        "city": "riyadh",
        "district": "النرجس",
        "bedrooms": 3,
        "bathrooms": 2,
        "area": 180,
        "images": ["https://..."],
        "created_at": "2025-01-15T10:30:00Z"
      }
    ],
    "pagination": {
      "page": 1,
      "limit": 20,
      "total": 45,
      "pages": 3
    }
  }
}
200 - نجاح 401 - غير مصرح

📡 Webhooks

استقبل إشعارات فورية عند حدوث أحداث مهمة مثل إضافة عميل جديد أو طلب معاينة.

الأحداث المدعومة

الحدث الوصف
client.created عميل جديد من المحادثة
client.interested عميل أبدى اهتماماً بعقار
viewing.requested طلب معاينة عقار
chat.phone_shared عميل شارك رقم جواله

مثال Webhook Payload

JSON Webhook 
{
  "event": "client.created",
  "timestamp": "2025-01-20T14:30:00Z",
  "data": {
    "client": {
      "id": "client_xyz789",
      "name": "أحمد محمد",
      "phone": "+966501234567",
      "interested_property": "prop_abc123"
    }
  },
  "signature": "sha256=..."
}
