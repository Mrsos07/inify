Query Parameters (اختيارية)
الحقلالنوعالوصف
statusstringfor_sale | for_rent | reserved | sold
typestringapartment | villa | land | office | commercial | duplex | studio | warehouse | building
citystringفلتر بالمدينة
is_activebooleantrue | false
pageintegerرقم الصفحة (افتراضي: 1)
per_pageintegerعدد النتائج (افتراضي: 20، أقصى: 100)

الاستجابة
{"success":true,"total":45,"page":1,"per_page":20,"pages":3,"properties":[{"id":"...","title":"...","price":850000,...}]}

Body (JSON)
الحقلالنوعإلزاميالوصف

property_typestring✓apartment|villa|land|office|commercial|duplex|studio|warehouse|building

citystring✓المدينة

GET /properties/<id>/ تفاصيل عقار محدد ►
curl -H "X-API-Key: YOUR_KEY" "{{ base_url }}<property-uuid>/"
PUT /properties/<id>/ تعديل عقار (أرسل الحقول المراد تعديلها فقط) ►
curl -X PUT -H "X-API-Key: YOUR_KEY" -H "Content-Type: application/json" \ -d '{"price":900000,"status":"reserved"}' \ "{{ base_url }}<property-uuid>/"
DELETE /properties/<id>/ حذف عقار ►
curl -X DELETE -H "X-API-Key: YOUR_KEY" "{{ base_url }}<property-uuid>/"
