# 🚀 دليل نشر Inify على Render.com

## 📋 نظرة عامة

هذا الدليل يشرح كيفية نشر Inify على Render.com مع:
- Django Web Application
- PostgreSQL Database (للتطبيق)
- Evolution API (WhatsApp)
- PostgreSQL Database (لـ Evolution API)

## 🔐 الخطوة 2: إعداد Render Account

1. **إنشاء حساب:** https://render.com/
2. **ربط GitHub:** Dashboard → Account Settings → Connect GitHub
3. **منح الصلاحيات:** اختر repository الخاص بـ Inify

---

## 📦 الخطوة 3: إنشاء الخدمات على Render

### 3.1 إنشاء Blueprint من render.yaml

1. **Dashboard** → **Blueprints** → **New Blueprint Instance**
2. **Connect Repository:** اختر `inify` repository
3. **Branch:** `main`
4. **Blueprint Name:** `inify-production`
5. **Apply**

Render سيقوم تلقائياً بإنشاء:
- ✅ PostgreSQL Database (inify-db)
- ✅ PostgreSQL Database (evolution-db)
- ✅ Evolution API Service
- ✅ Django Web Service

---

## 🔑 الخطوة 4: إعداد Environment Variables

### 4.1 متغيرات Django (inify-web)

انتقل إلى **inify-web** → **Environment** وأضف:

```bash
# Django Core (سيتم توليدها تلقائياً)
DJANGO_SECRET_KEY=<auto-generated>
ADMIN_SECRET_KEY=<auto-generated>

# Database (سيتم ربطها تلقائياً)
DATABASE_URL=<from-inify-db>

# AI APIs (أضفها يدوياً)
GEMINI_API_KEY=your-gemini-api-key
OPENAI_API_KEY=your-openai-api-key

# Evolution API (سيتم ربطها تلقائياً)
EVOLUTION_API_URL=https://evolution-api-inify.onrender.com
EVOLUTION_API_KEY=<copy-from-evolution-api-service>

# Google OAuth
GOOGLE_CLIENT_ID=your-google-client-id
GOOGLE_CLIENT_SECRET=your-google-client-secret

# Email Service
RESEND_API_KEY=your-resend-api-key
FROM_EMAIL=Inify <noreply@inify.ai>
SITE_URL=https://inify-web.onrender.com

# Cloudinary (اختياري)
CLOUDINARY_CLOUD_NAME=your-cloud-name
CLOUDINARY_API_KEY=your-api-key
CLOUDINARY_API_SECRET=your-api-secret

# Security
FIELD_ENCRYPTION_KEY=your-fernet-key
ALLOWED_HOSTS=.onrender.com,inify.ai,www.inify.ai
CSRF_TRUSTED_ORIGINS=https://inify-web.onrender.com,https://inify.ai,https://www.inify.ai
CORS_ALLOWED_ORIGINS=https://inify-web.onrender.com,https://inify.ai,https://www.inify.ai
```

### 4.2 متغيرات Evolution API

انتقل إلى **evolution-api** → **Environment**:

معظم المتغيرات موجودة في `render.yaml`، لكن تحقق من:
- ✅ `AUTHENTICATION_API_KEY` (سيتم توليده تلقائياً)
- ✅ `DATABASE_CONNECTION_URI` (سيتم ربطه تلقائياً)
- ✅ `SERVER_URL` (تأكد أنه صحيح)

## 🔄 الخطوة 5: Deploy

### 5.1 Deploy التلقائي

بعد إنشاء Blueprint، Render سيبدأ Deploy تلقائياً:

1. **evolution-db** → سيتم إنشاؤه أولاً
2. **evolution-api** → سينتظر evolution-db
3. **inify-db** → سيتم إنشاؤه
4. **inify-web** → سينتظر inify-db

### 5.2 مراقبة Deploy

راقب Logs لكل خدمة:
- **inify-web** → **Logs** → تحقق من عدم وجود أخطاء
- **evolution-api** → **Logs** → تحقق من الاتصال بـ database

---

## 🔧 الخطوة 6: إعداد Custom Domain (اختياري)

### 6.1 إضافة Domain

1. **inify-web** → **Settings** → **Custom Domains**
2. **Add Custom Domain:** `inify.ai`
3. **Add Custom Domain:** `www.inify.ai`

### 6.2 تحديث DNS

في مزود الدومين (Namecheap, GoDaddy, etc.):

```
Type    Name    Value                           TTL
CNAME   @       inify-web.onrender.com          3600
CNAME   www     inify-web.onrender.com          3600
```

### 6.3 تحديث Environment Variables

بعد إضافة Domain، حدّث:
```bash
ALLOWED_HOSTS=inify.ai,www.inify.ai,.onrender.com
CSRF_TRUSTED_ORIGINS=https://inify.ai,https://www.inify.ai
CORS_ALLOWED_ORIGINS=https://inify.ai,https://www.inify.ai
SITE_URL=https://inify.ai
```

## 🆘 استكشاف الأخطاء

### مشكلة: Build Failed
```bash
# تحقق من:
1. requirements.txt صحيح
2. build.sh موجود وقابل للتنفيذ
3. Python version صحيح (3.11)
```

### مشكلة: Database Connection Error
```bash
# تحقق من:
1. DATABASE_URL موجود في Environment Variables
2. inify-db يعمل بشكل صحيح
3. Migrations تم تشغيلها
```

### مشكلة: Evolution API لا يعمل
```bash
# تحقق من:
1. evolution-db يعمل
2. DATABASE_CONNECTION_URI صحيح
3. AUTHENTICATION_API_KEY موجود
```

### مشكلة: Static Files لا تظهر
```bash
# تحقق من:
1. collectstatic تم تشغيله في build.sh
2. STATIC_ROOT صحيح
3. WhiteNoise مثبت
```
